## 2. Фон и «земля»

Загрузите `bg.jpg` и растяните его под размер окна командой `pygame.transform.scale`:

```python
bg = pygame.image.load('images/bg.jpg')
bg = pygame.transform.scale(bg, (600, 450))
```

> **`pygame.transform.scale(картинка, (ширина, высота))`** — берёт картинку (`Surface`) и возвращает **новую картинку нужного размера**. Старая не меняется, результат нужно присвоить. Пропорции не сохраняются. Есть похожая команда `pygame.transform.smoothscale` — она делает то же самое, но сглаживает пиксели. `scale` работает быстрее, `smoothscale` — красивее.

Внизу экрана нарисуйте «землю» — прямоугольник высотой ~80 px, по которой бежит робот. Землю храните как отдельную переменную `ground_y` (Y-координата верхнего края земли):

```python
ground_y = 450 - 80   # = 370
```

## 3. Анимация персонажа

Анимация — это быстрая смена картинок. У нас есть список из 8 картинок, и каждый кадр игры мы показываем следующую по кругу.

### Шаг 3.1. Загрузка кадров в список

```python
walk_frames = []
for i in range(8):
    img = pygame.image.load(f'images/character_robot_walk{i}.png').convert_alpha()
    walk_frames.append(img)
```

Теперь `walk_frames[0]` — первый кадр, `walk_frames[7]` — восьмой. `len(walk_frames)` равно 8.

### Шаг 3.2. Класс игрока: храним кадры и счётчик

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.frames = walk_frames          # список всех кадров
        self.frame_index = 0               # какой кадр показываем сейчас
        self.anim_counter = 0              # сколько кадров игры прошло с прошлой смены
        self.image = self.frames[0]        # стартовая картинка
        self.rect = self.image.get_rect(midbottom=(x, y))

        # --- для прыжка (см. п.4) ---
        self.vel_y = 0
        self.on_ground = True
```

Три поля:
- `self.frames` — список картинок,
- `self.frame_index` — номер текущего кадра (от 0 до 7),
- `self.anim_counter` — таймер анимации.

### Шаг 3.3. Метод `update()` — сама анимация

```python
    def update(self):
        # 1) Анимация: каждые 6 кадров игры переключаем картинку
        self.anim_counter += 1
        if self.anim_counter >= 6:
            self.anim_counter = 0
            self.frame_index = (self.frame_index + 1) % len(self.frames)
            self.image = self.frames[self.frame_index]

            # 2) Подгоняем прямоугольник под новую картинку,
            #    сохраняя позицию (midbottom — «низ по центру», робот стоит на земле)
            self.rect = self.image.get_rect(midbottom=self.rect.midbottom)
```

Разбор построчно:

1. Каждый вызов `update()` (60 раз в секунду) увеличиваем `anim_counter` на 1.
2. Когда счётчик дошёл до 6 — прошло 6 кадров игры (0.1 секунды) — пора сменить картинку. Счётчик сбрасываем.
3. `(self.frame_index + 1) % len(self.frames)` — «следующий по кругу». Оператор `%` делает так, что после 7 идёт снова 0: `7 + 1 = 8`, `8 % 8 = 0`. Без него индекс выйдет за границы списка и игра упадёт с `IndexError`.
4. `self.image = self.frames[self.frame_index]` — берём нужную картинку из списка.
5. После смены картинки надо пересоздать `self.rect`. У разных кадров может быть разный размер, и если оставить старый `rect`, робот «дёрнется». `get_rect(midbottom=self.rect.midbottom)` создаёт новый прямоугольник с тем же положением низа по центру. Если этого не сделать — персонаж будет «прыгать» вверх-вниз во время бега.

**Почему 6, а не 1?** При 60 FPS смена каждый кадр выглядит как мельтешение. 6 кадров = 10 смен в секунду — «живая» скорость бега.

### Шаг 3.4. Проверка

Прежде чем идти дальше, убедитесь: робот стоит, но ножки двигаются. Если картинка не меняется — проверьте:
- `print(len(walk_frames))` действительно 8;
- `player.update()` вызывается в цикле;
- в конце `update()` есть строка с `get_rect(midbottom=...)`.

## 4. Прыжок

Нажатие `K_SPACE` или `K_UP` — прыжок через имитацию физики:

```python
if event.type == pygame.KEYDOWN and event.key in (pygame.K_SPACE, pygame.K_UP):
    if player.on_ground:
        player.vel_y = -15        # отрицательное = вверх
        player.on_ground = False
```

```python
# в конец Player.update():
self.vel_y += 1                   # гравитация тянет вниз
self.rect.y += self.vel_y

if self.rect.bottom >= ground_y:
    self.rect.bottom = ground_y   # ставим ровно на землю
    self.vel_y = 0
    self.on_ground = True
```

Числа `-15` и `1` можно подобрать: чем больше гравитация, тем «тяжелее» прыжок.

## 5. Препятствия справа налево

Раньше астероиды падали сверху вниз. Теперь препятствия движутся горизонтально.

```python
class Obstacle(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 60))
        self.image.fill((200, 60, 60))
        self.rect = self.image.get_rect(midbottom=(x, y))
        self.speed = random.randint(4, 8)

    def update(self):
        self.rect.x -= self.speed
        if self.rect.right < 0:
            self.kill()
```

Спавн по таймеру у правого края:

```python
if now - last_spawn > 1200:
```

## 6. Вывод текста на экран

До сих пор всё, что вы хотели показать игроку, выводилось `print()` в консоль. Теперь текст должен быть на картинке игры. В Pygame `font` «рисует» строку в картинку (`Surface`), а картинку вы выводите через `blit`.

### Шаг 6.1. Создать шрифт один раз

```python
# создаём шрифт ОДИН РАЗ при старте игры (вне цикла!)
font = pygame.font.SysFont(None, 36)
```

- `None` — системный шрифт по умолчанию;
- `36` — размер в пикселях.

### Шаг 6.2. Превратить строку в картинку

```python
text_surface = font.render("Счёт: 0", True, (255, 255, 255))
```

`font.render` принимает:
1. строку (можно f-строку: `f"Счёт: {score}"`);
2. сглаживание — всегда `True`;
3. цвет текста — кортеж `(R, G, B)`.

**Результат `render` — обычная картинка (`Surface`)**, не текст. Её можно `blit`-ить как спрайт.

### Шаг 6.3. Вывести картинку с текстом на окно

```python
# в цикле отрисовки, ПОСЛЕ отрисовки фона и спрайтов:
text_surface = font.render(f"Счёт: {score}", True, (255, 255, 255))
window.blit(text_surface, (10, 10))   # (10, 10) — левый верхний угол
```

Для жизней:

```python
health_surface = font.render(f"Жизни: {health}", True, (255, 80, 80))
window.blit(health_surface, (450, 10))
```

### Шаг 6.4. Полный блок

```python
score = 0
health = 3

# ... в цикле, перед pygame.display.update():

score_text = font.render(f"Счёт: {score}", True, (255, 255, 255))
health_text = font.render(f"Жизни: {health}", True, (255, 80, 80))

window.blit(score_text, (10, 10))
window.blit(health_text, (450, 10))
```

> **Частая ошибка №1:** создать `font.render(...)` один раз до цикла — число «запекается» навсегда. Если число меняется — `render` вызывайте каждый кадр.
>
> **Частая ошибка №2:** вывести текст до спрайтов — спрайт перекроет текст. Выводите текст после `all_sprites.draw(window)`.
>
> **Если текст не виден на светлом фоне** — выберите контрастный цвет (чёрный `(0, 0, 0)`), либо нарисуйте под текстом полупрозрачный прямоугольник: `pygame.draw.rect(window, (0, 0, 0), (5, 5, 200, 40))` перед `blit`.
